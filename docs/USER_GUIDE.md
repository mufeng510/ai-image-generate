# 用户指南

## 快速开始

1. **安装软件**：运行 Windows 安装程序，完成安装。
2. **启动应用**：双击桌面图标启动“豆包批量生图”。
3. **创建项目**：在“项目管理”页面，点击“创建项目”，填写项目名称和路径。
4. **添加参考图片**：在项目文件夹的 `references/` 目录下放入图片文件。
5. **编写提示词**：在“项目管理”页面编辑 `prompt.txt`。
6. **添加账号**：在“账号管理”页面，添加豆包账号，并在可见浏览器中手动登录。
7. **创建任务**：在“任务队列”页面，创建任务，选择项目和账号。
8. **开始任务**：点击“开始”，软件将自动抽取参考图片、上传、提交生成、下载结果。

## 项目目录结构

```
项目名称/
├── prompt.txt              # 提示词
├── references/             # 参考图片
│   ├── 场景A/
│   │   ├── a.jpg
│   │   └── b.jpg
│   └── 场景B/
│       └── c.jpg
└── output/                 # 生成结果
    ├── 20261101_164500_123/
    │   ├── 001.png
    │   ├── 002.png
    │   ├── prompt.txt
    │   ├── references.json
    │   └── task.json
    └── ...
```

## 账号管理

每个账号使用独立的 Chromium 用户数据目录，登录状态持久化保存。登录时，请在可见浏览器中手动输入账号密码或扫码登录。

## 任务状态说明

- **pending**: 等待中
- **preparing**: 准备中
- **selecting_images**: 抽图中
- **waiting_confirmation**: 等待确认
- **uploading**: 上传中
- **submitting**: 提交中
- **generating**: 生成中
- **downloading**: 下载中
- **verifying**: 校验中
- **completed**: 已完成
- **paused**: 已暂停
- **failed**: 失败
- **cancelled**: 已取消
- **needs_manual_intervention**: 需人工干预

## 常见问题

### 登录失效
软件会暂停任务，提示用户在可见浏览器中手动登录。登录完成后，点击“继续执行”。

### 验证码
遇到验证码时，任务暂停，等待用户在浏览器中手动处理。

### 网页结构变化
若豆包网页结构发生变化导致自动化失败，任务会停止并保存诊断信息（截图、HTML、URL），请联系开发者。
