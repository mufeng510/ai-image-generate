# 用户指南

## 使用前准备

安装版应用为单文件安装包，**已内置 Node.js 与 Playwright Chromium（约 300–500MB）**，无需用户自行安装任何运行时。

（仅在源码开发/自行构建时才需要本机安装 Node.js 与 Rust。）

## 快速开始

1. **安装软件**：运行 Windows 安装程序，完成安装。
2. **启动应用**：双击桌面图标启动“豆包批量生图”。
3. **创建项目**：在“项目管理”页面，点击“创建项目”，填写项目名称和路径。
4. **添加参考图片**：在项目文件夹的 `references/` 目录下放入图片文件。
5. **编写提示词**：在“项目管理”页面编辑 `prompt.txt`。
6. **添加账号**：在“账号管理”页面，添加豆包账号，并在可见浏览器中手动登录。
7. **创建任务**：在“任务队列”页面，选择项目和账号即可创建任务；无需填写任务名称，软件会自动以“项目名-日期”命名（例如：奶瓶收纳盒生图-2026-11-06）。
8. **开始任务**：点击“开始”，软件将自动抽取参考图片、上传、提交生成、下载结果。
9. **查看成果**：在“任务队列”页面点任务→“查看”，进入轮次详情页可预览图片、查看校验状态；点“打开目录”可直接在文件管理器中定位该批次的输出文件夹（`output/时间戳/`）。

## 项目目录结构

```
项目名称/
├── prompt.txt              # 提示词
├── references/             # 参考图片
│   ├── 场景A/
│   │   ├── a.jpg
│   │   └── b.jpg
│   └── 场景B/
│       └── c.jpg
└── output/                 # 生成结果
    ├── 20261101_164500_123/
    │   ├── 001.png
    │   ├── 002.png
    │   ├── prompt.txt
    │   ├── references.json
    │   └── task.json
    └── ...
```

## 账号管理

每个账号使用独立的 Chromium 用户数据目录，登录状态持久化保存。登录时，请在可见浏览器中手动输入账号密码或扫码登录。

每个账号可单独设置「阈值」（累计已校验图片上限：正数 = 累计总额度，0 = 跟随「设置」中的默认账号每日生图额度，负数 = 完全不限制）；达到上限后该账号会被自动轮换跳过，任务在轮次开始前暂停并通知。「设置」中的「默认账号每日生图额度」按本地自然日计算（0 = 不限制），仅为本软件的任务分配参考，实际生图额度以豆包实际为准。

## 任务状态说明

- **pending**: 等待中
- **preparing**: 准备中
- **selecting_images**: 抽图中
- **waiting_confirmation**: 等待确认
- **uploading**: 上传中
- **submitting**: 提交中
- **generating**: 生成中
- **downloading**: 下载中
- **verifying**: 校验中
- **completed**: 已完成
- **paused**: 已暂停
- **failed**: 失败
- **cancelled**: 已取消
- **needs_manual_intervention**: 需人工干预

## 常见问题

### 登录失效
软件会暂停任务，提示用户在可见浏览器中手动登录。登录完成后，点击“继续执行”。

### 豆包弹出广告/推广遮罩层
软件现在会自动尝试关闭豆包页面上的广告、签到、推广等遮罩层（关闭按钮 → Escape → 点击遮罩角落，多轮重试）。如果遮罩仍无法自动关闭，任务会停在“需人工干预”，请在可见浏览器中手动关闭遮罩，然后点击任务行上的“继续执行”。

### 任务“需人工干预”怎么继续
人工处理后（例如手动关闭遮罩、在浏览器中点击“发送”等），点击任务行上的“继续执行”按钮：

- 页面已有生成图片 / 已提交正在生成 → 软件直接等待生成完成，然后继续提取、下载、校验；
- 输入框里有未发送的提示词 → 请在浏览器中确认后点击“发送”，再点一次“继续执行”；
- 页面是全新对话、从未提交 → 软件会完整重新执行本任务（不会造成重复提交）。

软件不会在状态不明时自动点击“发送”，避免重复提交浪费生图额度。

### 验证码
遇到验证码时，任务暂停，等待用户在浏览器中手动处理。

### 网页结构变化
若豆包网页结构发生变化导致自动化失败，任务会停止并保存诊断信息（截图、HTML、URL），请联系开发者。
